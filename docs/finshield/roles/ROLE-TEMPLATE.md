# Role template

How to use this file: copy it into `roles/NN-new-role/README.md` for a new role. To add more detail to an existing role, add a topic file such as `kyc-rule-notes.md` in that role's folder and link it under the last heading. Shared contracts and scenario rules stay in [contracts.md](../contracts.md) and [scenarios.md](../scenarios.md). Notes propose changes and link to the agreed result instead of copying it.

Delete this note and the guidance lines (the lines in italics) once you have filled the file in.
